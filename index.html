BETPILOT BUCO NERO

A private, personal-use automation for collecting and maintaining a time-series database of football match observations.

What the project does

BETPILOT BUCO NERO collects football match exports, including event timestamps, match statistics and pre-match/live market data, and organizes them into a versioned research database.

The pipeline transfers exported ZIP and CSV files to the operator’s Google Drive, verifies the data, reconstructs match timelines and stores successive SQLite database versions. GitHub Actions runs controlled checks and publication tasks.

Why Google Drive access is requested

Google Drive is the operator’s archive for source exports and database versions. The OAuth connection used by rclone currently requests full Drive access (https://www.googleapis.com/auth/drive), although the intended workflows operate only on designated BETPILOT folders. This permission technically allows the application to view, create, modify and delete other Drive files; the operator should therefore keep its credentials protected and review this permission periodically.

Who can use it?

This integration is currently intended exclusively for the project operator’s own Google account. This site is informational: it has no account registration, does not provide public Google sign-in, and does not offer access to the research database.

For details of data access, storage, sharing, and deletion, read the Privacy Policy. You can also review the Terms.
