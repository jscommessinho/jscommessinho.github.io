Privacy Policy

How the personal-use BETPILOT BUCO NERO integration accesses and processes Google account information.

1. Controller and scope

This project is operated by the owner of the GitHub account jscommessinho, for that operator's own use. This notice describes the Google Drive connection used for the private research archive, not a service offered to public users.

2. Data accessed

The application requests the Google Drive OAuth scope https://www.googleapis.com/auth/drive. This is a broad permission that technically permits access to all files in the authorized account's Drive (excluding the special Application Data Folder), not only BETPILOT files. The configured processing tasks are intended to operate on the specific folders used to store imported ZIP/CSV exports, SQLite master databases, logs and backups.

3. Purpose and use

Authorized Drive access is used to read exported match data, check file completeness and integrity, deduplicate and reconstruct chronological observations, store incremental database versions, and recover the latest valid backup. The operator may subsequently analyze the archived match data separately. The integration is not designed to use Google account data for advertising or resale.

4. Where data is stored and who processes it

Source exports and versioned databases are retained in the operator's Google Drive. Authorized GitHub Actions workflows temporarily process copies on GitHub-hosted runners, and may produce execution logs. OAuth configuration is stored on the operator's authorized device and as a protected GitHub Actions repository secret. Google and GitHub process information as infrastructure providers under their own applicable terms and privacy policies. The public GitHub Pages site does not expose the private database or credentials.

5. Retention, access and deletion

The operator retains research archives and backups for ongoing project use until they are intentionally deleted. The operator can delete selected Drive files, remove the GitHub repository secret, or revoke the Google authorization from Google Account security settings. GitHub workflow logs follow the applicable repository settings and GitHub retention rules.

6. Access and sharing

The integration is restricted operationally to the project operator. It does not intentionally publish Google Drive documents, sell Google user information, or share them with advertisers. Google and GitHub necessarily handle information to provide their infrastructure. As the Drive scope grants broad technical access, the operator is responsible for safeguarding the credentials and limiting workflow code to intended folders.

7. Public website

This informational GitHub Pages website has no custom analytics, cookies, contact forms, or account registration scripts. GitHub may collect standard service and access logs according to its own privacy policy.

8. Contact and changes

For privacy questions, contact the operator through the GitHub profile or the support email displayed on the OAuth consent screen. This notice may be updated if the application's purposes or permissions change.
